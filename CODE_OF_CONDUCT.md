# Código de conducta

Este es un proyecto de afición sobre naturaleza. Aquí se trata a las personas con respeto y se discute con datos y fuentes.

- Sé amable y paciente, también con quien se equivoca o escribe en un idioma que no domina.
- Discute el contenido, no a las personas. No se tolera el acoso, los insultos ni la discriminación.
- No publiques datos personales de nadie.
- Quien modera puede editar, cerrar o borrar aportaciones y bloquear a quien incumpla estas normas.

Para avisar de un problema de conducta, abre una incidencia marcada como privada o escribe a quien mantiene el repositorio (`elobservario-a11y`).
